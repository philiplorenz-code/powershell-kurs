<Uebung nr="2.1" titel="Fehler abfangen">

1. Führe `Get-Content C:\Kurs\gibt-es-nicht.txt` in einem `try`/`catch` aus, ohne weitere Parameter. Wird der `catch`-Block ausgeführt? Warum (nicht)?
2. Ändere es so, dass der `catch` greift. Gib eine verständliche Meldung mit `$_.Exception.Message` aus.
3. Füge einen `finally`-Block hinzu, der „Fertig." ausgibt. Wann läuft er?
4. *(Bonus)* Lies den Typ des Fehlers aus (`$_.Exception.GetType().FullName`) und schreibe einen **speziellen** `catch` für genau diesen Fehlertyp.

<Tipps items={[{"huerde": "Der `catch`-Block läuft nicht", "tipp": "Das ist die Falle: `Get-Content` meldet einen **nicht-terminierenden** Fehler. Füge `-ErrorAction Stop` hinzu, dann greift der `catch`."}, {"huerde": "Ich weiß nicht, wie ich die Meldung ausgebe", "tipp": "Im `catch` steht der Fehler in `$_`. `$_.Exception.Message` ist der lesbare Text."}, {"huerde": "Wie finde ich den Fehlertyp?", "tipp": "(Bonus) `$_.Exception.GetType().FullName`. Den Namen schreibst du in eckige Klammern: `catch [Typname] { … }`."}]} />

<Loesung>

```powershell
# 1. Der catch greift NICHT: nicht-terminierender Fehler
try { Get-Content C:\Kurs\gibt-es-nicht.txt }
catch { "Fehler abgefangen" }

# 2. -ErrorAction Stop macht ihn terminierend
try { Get-Content C:\Kurs\gibt-es-nicht.txt -ErrorAction Stop }
catch { "Fehler: $($_.Exception.Message)" }

# 3. finally läuft immer
try { Get-Content C:\Kurs\gibt-es-nicht.txt -ErrorAction Stop }
catch { "Fehler: $($_.Exception.Message)" }
finally { "Fertig." }

# 4. Fehlertyp
try { Get-Content C:\Kurs\gibt-es-nicht.txt -ErrorAction Stop }
catch { $_.Exception.GetType().FullName }
# -> System.Management.Automation.ItemNotFoundException

try { Get-Content C:\Kurs\gibt-es-nicht.txt -ErrorAction Stop }
catch [System.Management.Automation.ItemNotFoundException] { "Datei nicht gefunden" }
catch { "Anderer Fehler: $($_.Exception.Message)" }
```

</Loesung>
</Uebung>

<Uebung nr="2.2" titel="Robuste Funktion">

Gerüst: `try { Get-Content … -ErrorAction Stop } catch { Write-Warning … }`. Schreibe die Funktion `Read-DateiSicher` mit `-Pfad`. Sie liest die Datei und gibt den Inhalt zurück. Existiert die Datei nicht, gibt sie eine **Warnung** (`Write-Warning`) aus und liefert nichts zurück. Teste mit `C:\Windows\win.ini` und mit einer nicht vorhandenen Datei.

<Tipps items={[{"huerde": "Ich weiß nicht, wie ich anfangen soll", "tipp": "Gerüst: `function Read-DateiSicher { param($Pfad) try { Get-Content … } catch { Write-Warning … } }`."}, {"huerde": "Die Funktion meldet nichts, obwohl die Datei fehlt", "tipp": "`Get-Content -Path $Pfad -ErrorAction Stop`. Ohne `Stop` springt PowerShell nicht in den `catch`."}, {"huerde": "Ich weiß nicht, wie eine Warnung aussieht", "tipp": "`Write-Warning \"Datei '$Pfad' konnte nicht gelesen werden\"`. Die Funktion gibt dann nichts zurück."}]} />

<Loesung>

```powershell
function Read-DateiSicher {
    param([Parameter(Mandatory = $true)][string]$Pfad)

    try {
        Get-Content -Path $Pfad -ErrorAction Stop
    }
    catch {
        Write-Warning "Datei '$Pfad' konnte nicht gelesen werden: $($_.Exception.Message)"
    }
}

Read-DateiSicher -Pfad C:\Windows\win.ini
Read-DateiSicher -Pfad C:\nichtda.txt
```

Das Verb `Read` ist ein genehmigtes Verb (`Get-Verb`).

</Loesung>
</Uebung>

<Uebung nr="2.3" titel="Mehrere Rechner, ein Fehler">

Ein Skript soll den Dienst `Spooler` auf mehreren Rechnern abfragen. Einer davon existiert nicht.

1. Hinweis: `Get-Service -ComputerName` gibt es in PowerShell 7 nicht. Nutze `Invoke-Command` pro Rechner.
2. Nimm pro Rechner einen `try/catch` innerhalb einer `foreach`-Schleife. Lasse die Liste `@("PSLAB-02", "PSLAB-03", "GIBTSNICHT")` durchlaufen.
3. Fange den Fehler für den ungültigen Rechner ab, gib eine Warnung mit dem Rechnernamen aus und mache mit dem nächsten Rechner weiter.

<Tipps items={[{"huerde": "Ich weiß nicht, wie ich mehrere Rechner nacheinander abfrage", "tipp": "`foreach ($r in $rechner) { … }` mit einem `try/catch` **innerhalb** der Schleife."}, {"huerde": "Der Fehler stoppt meine ganze Schleife", "tipp": "Der `catch` muss pro Durchlauf stehen, nicht um die Schleife herum. Dann geht es mit dem nächsten Rechner weiter."}, {"huerde": "Der Fehler wird nicht abgefangen", "tipp": "Hänge `-ErrorAction Stop` an den `Invoke-Command`-Aufruf, sonst bleibt der Fehler nicht-terminierend."}]} />

<Loesung>

```powershell
$rechner = @("PSLAB-02", "PSLAB-03", "GIBTSNICHT")

foreach ($r in $rechner) {
    try {
        Invoke-Command -ComputerName $r -ScriptBlock { Get-Service -Name Spooler } -ErrorAction Stop |
            Select-Object PSComputerName, Name, Status
    }
    catch {
        Write-Warning "$r nicht erreichbar: $($_.Exception.Message)"
    }
}
```

Die Schleife läuft weiter, weil der Fehler im `catch` behandelt wurde.

</Loesung>
</Uebung>

<Uebung nr="2.4" titel="Fehlersuche mit Verbose und Breakpoints">

1. *(Bonus)* Erweitere `Get-FreierSpeicher` aus Block 1 um `[CmdletBinding()]` und eine `Write-Verbose`-Zeile („Lese Laufwerk X"). Rufe sie mit und ohne `-Verbose` auf.
2. Das folgende Skript soll die Summe von 1 bis 10 berechnen und ergibt nicht 55. Finde den Fehler mit einem Breakpoint und den Debug-Befehlen:

```powershell
$summe = 0
foreach ($i in 1..10) {
    $summe = $i
}
$summe
```

Speichere es als `C:\Kurs\Skripte\Summe.ps1`, setze `Set-PSBreakpoint -Script ... -Line 3`, starte es und beobachte `$i` und `$summe`. Behebe den Fehler.

<Tipps items={[{"huerde": "Ich weiß nicht, wie ich Verbose-Meldungen anzeige", "tipp": "(Bonus) `[CmdletBinding()]` vor `param(...)` und `Write-Verbose \"…\"` in die Funktion. Anzeige mit `-Verbose`."}, {"huerde": "Der Breakpoint löst nicht aus", "tipp": "`Set-PSBreakpoint -Script C:\\Kurs\\Skripte\\Summe.ps1 -Line 3`. Danach das Skript über seinen **Pfad** starten, nicht einzelne Zeilen markieren."}, {"huerde": "Ich sehe den Fehler im Code nicht", "tipp": "Am Prompt `[DBG]:` tippst du `$i` und `$summe`. Wird `$summe` addiert oder überschrieben? Die Lösung ist ein Zeichen: `+=`."}]} />

<Loesung>

```powershell
function Get-FreierSpeicher {
    [CmdletBinding()]
    param([string]$Laufwerk = "C")

    Write-Verbose "Lese Laufwerk $Laufwerk"
    $d = Get-PSDrive -Name $Laufwerk
    [PSCustomObject]@{ Laufwerk = $Laufwerk; FreiGB = [math]::Round($d.Free / 1GB, 1) }
}
Get-FreierSpeicher
Get-FreierSpeicher -Verbose
```

```powershell
Set-PSBreakpoint -Script C:\Kurs\Skripte\Summe.ps1 -Line 3
C:\Kurs\Skripte\Summe.ps1
# Am Prompt [DBG]:  $i  und  $summe  eingeben, mit  c  fortsetzen
Get-PSBreakpoint | Remove-PSBreakpoint
```

Fehler: In Zeile 3 steht `$summe = $i` statt `$summe += $i`. Der Wert wird überschrieben und nicht addiert.

$cred = Get-Credential -UserName "PSLAB\teilnehmer01" -Message "Passwort eingeben"

Invoke-Command -ComputerName PSLAB-02 -Credential $cred -ScriptBlock { whoami }

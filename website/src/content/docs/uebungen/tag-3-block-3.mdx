<Uebung nr="3.1" titel="Web-API abfragen" typ="Übung">

1. Rufe mit `Invoke-RestMethod` die Daten für `https://api.github.com/users/octocat` ab und speichere sie in `$user`.
2. Gib `login`, `name` und `public_repos` aus.
3. Speichere das Ergebnis als JSON in `C:\Kurs\Ausgabe\octocat.json` (`ConvertTo-Json`).
4. *(Bonus)* Ruf einen Benutzer ab, den es nicht gibt (`falscher-benutzer-1234567`) und fange den Fehler mit `try`/`catch` ab. Gib den HTTP-Statuscode aus.

<Tipps items={[{"huerde": "Ich bekomme keine Daten aus der API", "tipp": "`$user = Invoke-RestMethod -Uri 'https://api.github.com/users/octocat'`. Internetzugang nötig."}, {"huerde": "Wie greife ich auf einzelne Felder zu?", "tipp": "Die Antwort ist schon ein Objekt: `$user.login`, `$user.name`, `$user.public_repos`."}, {"huerde": "Wie speichere ich als JSON?", "tipp": "`$user | ConvertTo-Json | Set-Content C:\\Kurs\\Ausgabe\\octocat.json`. Den Fehlerfall (Bonus) fängst du mit `try/catch` und `-ErrorAction Stop`."}]} />

<Loesung>

```powershell
$user = Invoke-RestMethod -Uri "https://api.github.com/users/octocat"
"Login: $($user.login)"
"Name:  $($user.name)"
"Repos: $($user.public_repos)"
$user | ConvertTo-Json | Set-Content C:\Kurs\Ausgabe\octocat.json

try {
    Invoke-RestMethod -Uri "https://api.github.com/users/falscher-benutzer-1234567" -ErrorAction Stop
}
catch {
    "Fehler: $($_.Exception.Response.StatusCode)"     # NotFound
}
```

</Loesung>

<Uebung nr="3.3" titel="Zeitgesteuert ausführen">

1. Schreibe ein Skript `C:\Kurs\Skripte\LogDemo.ps1`, das mit `Add-Content` eine Zeile mit Datum und Uhrzeit in `C:\Kurs\Logs\demo.log` schreibt (z. B. `Add-Content -Path … -Value (Get-Date)`).
2. Lege mit `New-ScheduledTaskAction`, `New-ScheduledTaskTrigger` und `Register-ScheduledTask` eine Aufgabe `Kurs-LogDemo` an, die dieses Skript mit `pwsh.exe` **täglich um 09:00** ausführt.
3. Starte die Aufgabe sofort mit `Start-ScheduledTask` und prüfe, ob die Logdatei eine neue Zeile hat und wie `LastTaskResult` lautet.
4. Entferne die Aufgabe wieder.

<Tipps items={[{"huerde": "Ich weiß nicht, was das Skript schreiben soll", "tipp": "`Add-Content -Path C:\\Kurs\\Logs\\demo.log -Value \"Lauf am $(Get-Date)\"` in die Datei `LogDemo.ps1`."}, {"huerde": "Ich verstehe Aktion und Trigger nicht", "tipp": "Aktion: `New-ScheduledTaskAction -Execute 'C:\\Program Files\\PowerShell\\7\\pwsh.exe' -Argument '-File C:\\Kurs\\Skripte\\LogDemo.ps1'`. Trigger: `New-ScheduledTaskTrigger -Daily -At 09:00`."}, {"huerde": "Die Logdatei bleibt leer oder das Ergebnis ist 267011", "tipp": "Gib dem Task ein paar Sekunden: `Start-ScheduledTask`, kurz warten, dann `Get-ScheduledTaskInfo`. `0` = Erfolg, `267009` = läuft noch, `267011` = noch nicht gelaufen."}]} />

<Loesung>

```powershell
Set-Content C:\Kurs\Skripte\LogDemo.ps1 -Value 'Add-Content -Path C:\Kurs\Logs\demo.log -Value "Lauf am $(Get-Date)"'

$aktion  = New-ScheduledTaskAction -Execute 'C:\Program Files\PowerShell\7\pwsh.exe' `
           -Argument '-NoProfile -File "C:\Kurs\Skripte\LogDemo.ps1"'
$trigger = New-ScheduledTaskTrigger -Daily -At 09:00
Register-ScheduledTask -TaskName 'Kurs-LogDemo' -Action $aktion -Trigger $trigger

Start-ScheduledTask -TaskName 'Kurs-LogDemo'
Start-Sleep -Seconds 10
Get-Content C:\Kurs\Logs\demo.log
Get-ScheduledTaskInfo -TaskName 'Kurs-LogDemo' | Select-Object LastRunTime, LastTaskResult

Unregister-ScheduledTask -TaskName 'Kurs-LogDemo' -Confirm:$false
```

`LastTaskResult` von `0` heißt: erfolgreich. `267009` heißt „läuft noch“, `267011` „noch nicht gelaufen“: kurz warten und den Befehl wiederholen.

</Loesung>

<Uebung nr="3.4" titel="Transcript und eigenes Log">

1. Erweitere `LogDemo.ps1` so, dass sie mit `Start-Transcript` ein Transcript in `C:\Kurs\Logs\LogDemo-transcript.log` aufzeichnet und am Ende `Stop-Transcript` aufruft. Dazwischen: `Get-Date` und die ersten drei Prozesse.

3. *(Bonus)* Schreibe eine Funktion `Write-Log` (Parameter `-Message`, `-Level` mit Standard `INFO`), die eine Zeile `2026-10-04 09:00:00 [INFO] Text` an `C:\Kurs\Logs\skript.log` anhängt. Rufe sie dreimal auf, einmal mit `-Level WARN`.

<Tipps items={[{"huerde": "Ich weiß nicht, wie ich das Transcript einbinde", "tipp": "Erste Zeile `Start-Transcript -Path C:\\Kurs\\Logs\\LogDemo-transcript.log -Append`, letzte Zeile `Stop-Transcript`."}, {"huerde": "Ich weiß nicht, was im Transcript stehen soll", "tipp": "Öffne es mit `Get-Content`. Oben stehen Zeitpunkt, Benutzer und Rechner, unten der Endzeitpunkt."}, {"huerde": "Wie baue ich die Logzeile?", "tipp": "(Bonus) `'{0:yyyy-MM-dd HH:mm:ss} [{1}] {2}' -f (Get-Date), $Level, $Message` und `Add-Content`."}]} />

<Loesung>

```powershell
# LogDemo.ps1
Start-Transcript -Path C:\Kurs\Logs\LogDemo-transcript.log -Append
"Start: $(Get-Date)"
Get-Process | Select-Object -First 3
"Ende: $(Get-Date)"
Stop-Transcript
```

```powershell
function Write-Log {
    param(
        [Parameter(Mandatory = $true)][string]$Message,
        [string]$Level = 'INFO'
    )
    $zeile = '{0:yyyy-MM-dd HH:mm:ss} [{1}] {2}' -f (Get-Date), $Level, $Message
    Add-Content -Path C:\Kurs\Logs\skript.log -Value $zeile
}
Write-Log "Skript gestartet"
Write-Log "Dienst fehlt" -Level WARN
Write-Log "Skript beendet"
Get-Content C:\Kurs\Logs\skript.log
```

Das Transcript beginnt mit einem Kopf (Zeitpunkt, Benutzer, Rechner, PowerShell-Version) und endet mit dem Endzeitpunkt.
